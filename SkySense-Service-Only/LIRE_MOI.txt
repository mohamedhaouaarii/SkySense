SkySense - SERVICE seulement (Oracle via ODBC)
=============================================
1. Ouvrir SkySense.pro dans Qt Creator (kit Qt 6 64 bits avec le module SQL / pilote QODBC).
2. Source ODBC 64 bits nommee SKYSENSE -> pilote Oracle, service localhost:1521/XEPDB1.
   Compte Oracle : SKYSENSE / sky123.
3. Une seule fois dans SQL*Plus :  sqlplus SKYSENSE/sky123@localhost:1521/XEPDB1
                                    SQL> @service_sqlplus.sql
4. Build > Rebuild Project, puis Run : l'application s'ouvre directement sur Services.
   Add = INSERT, Edit = UPDATE, Delete = DELETE (voir GUIDE_SERVICE_ORACLE.txt).
Connexion : connection.h / connection.cpp = Singleton de Meyers de l'atelier.
